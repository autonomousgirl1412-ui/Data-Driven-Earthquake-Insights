# DATA-DRIVEN EARTHQUAKE INSIGHTS:
 
# Project Overview

Data-Driven Earthquake Insights is a project that analyzes earthquake activity using data from the previous five years. The project covers data retrieval, data cleaning, MySQL database storage, SQL analysis, and interactive visualization using Streamlit.

# Objectives

- Data retrival from usgs API for a defined time range
- Raw data cleaning and pre-processing using python(pandas and regex)
- Mysql data insertion and connection
- Problem statement solutions using sql queries
- Streamlit dashboard creation
